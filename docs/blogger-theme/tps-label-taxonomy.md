# Bench Notes label taxonomy

Apply on key posts (Blogger Labels field). Prefer lowercase except brand phrases.

## Core (always consider)

| Label | Use when |
|-------|----------|
| `lab methods` | Teaching protocol / method literacy |
| `Bench Notes` | Long-form teaching series posts |
| `calculators` | Interactive tool posts/pages |

## Topic shelves

| Label | Examples |
|-------|----------|
| `virology` | TCID50, plaque, MOI, reporters, titers |
| `cloning` | ligation, assembly, insert:vector |
| `imaging` | fluorescent tags, IFA, nanobodies |
| `QC` | controls, assay validity, failure modes |
| `molecular biology` | broad foundational literacy |

## Do not use on science primary shelf

Entertainment, sports, exam-prep, software-download labels — keep off homepage featured and primary nav.
